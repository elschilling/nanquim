# Nanquim v0.1.0-alpha.2

**Prepared — release qualification is in progress.**

`v0.1.0-alpha.2` brings safer native SVG documents, more predictable editing,
an original visual identity, image editing, and expanded CAD tools. It remains
an alpha for evaluation and compatibility feedback. Keep independent copies of
important drawings, especially before opening files saved by an older version.

## Highlights

- New/Open/Save/Save As share unsaved-change protection and a transactional
  document lifecycle. Rejected files leave the current drawing intact, and
  native SVG saves preserve collections, styles, blocks, Paper data, imported
  definitions, and Geometry Nodes metadata through the qualified round trips.
- Nanquim now has its own pen-nib mark and command icons, three appearance
  presets, custom accent/background colors, and a resizable command palette.
  F1 opens searchable illustrated Help; F4 toggles the palette.
- Local PNG, JPEG, GIF, and WebP images can be inserted with `IMAGE` or file
  drop, resized, moved, and cropped with Undo/Redo. Images are embedded, and
  cropping remains editable after native SVG save/reopen and clipboard copy.
- Outliner drag-and-drop, keyboard moves, Shift-click ranges, and an `M`
  collection-move dialog make drawing organization easier while preserving
  positions, styles, and Undo/Redo.
- `JOIN` combines supported connected lines and curves; `OFFSET` adds open or
  closed polylines and circular arcs; `FILLET` rounds rectangle corners; and
  `HATCH` accepts selected rectangles and explicitly closed paths, including
  curved and compound boundaries. These operations reject unsupported input
  before changing the drawing.
- Dimension styles add orientation and text-position controls. Dimensions and
  distance measurements have live guides; snapping, polyline closure, spline
  Ortho, Mirror, Trim, and Extend receive focused workflow fixes.
- Completed editing operations use consistent History transactions for the
  qualified paths. Rotate preserves affine-transformed geometry and metadata;
  command cancellation, grip edits, and Undo/Redo have broader regression
  coverage.
- One-sheet Paper output and SVG/DXF exchange have explicit qualification
  profiles, diagnostics, browser workflows, and reproducible performance
  budgets. Click the Nanquim icon to reopen Welcome and browse dated changes.

See the [changelog](https://github.com/elschilling/nanquim/blob/master/CHANGELOG.md)
for individual changes and their implementation commits.

## Compatibility

- Application version: `0.1.0-alpha.2`.
- Native Nanquim SVG saves use document schema **3**. This release includes the
  schema-v3 document work added after `v0.1.0-alpha.1`, which saved schema 2.
  Supported schema-1 and schema-2 documents migrate in memory on Open and stay
  marked unsaved until an explicit Save writes the current format. Use Save As
  and keep the original when compatibility with an older Nanquim matters.
- Geometry Nodes document metadata and graph schemas remain **1**. Preparing
  this application release does not advance either saved-data schema.
- Desktop Chromium stable and the previous stable release are the primary
  browser targets. Firefox stable and ESR use portable upload/download file
  workflows. Safari/WebKit remains best-effort; mobile and touch-first editing
  are not supported.
- Direct overwrite and persistent recent-file handles require a secure context
  and the browser File System Access API. Download-only Save As keeps the
  drawing marked unsaved because the browser cannot confirm the file was kept.
- The document source limit is 64 MiB, with a 100,000-element SVG safety budget.
  Images are Model Space only, one file at a time, up to 8 MiB and 40 million
  decoded pixels per image. These are safety limits, not performance promises.

See the [native document contract](https://github.com/elschilling/nanquim/blob/master/docs/native-document-format.md)
and [browser support policy](https://github.com/elschilling/nanquim/blob/master/docs/browser-support.md).

## Known limitations

- SVG/DXF exchange and Paper SVG/PDF output remain **Partial**. Native SVG is
  the editable source; presentation and interchange exports can lose features.
  Inspect exported files in the intended receiving application.
- DXF exchange covers common Model entities and representable layers, not every
  entity or vendor extension. DXF text import, native metadata, Paper data, and
  arbitrary SVG paint or curves are outside the qualified profile.
- Paper supports one sheet with multiple viewports. Per-color plot lineweights,
  multiple sheets, and title-block workflows remain deferred. Color mapping
  preserves existing stroke widths.
- Many modification tools deliberately reject transformed or specialized
  geometry outside their qualified cases. JOIN requires connected,
  non-branching geometry sharing a parent; mixed joined curves retain their
  SVG shape but cannot retain each source's specialized arc/spline grips.
- Inspector fields, collection settings, and saved-view navigation mark the
  drawing dirty but are not individual Undo entries. New/Open reset History.
- Cropping hides pixels without deleting them: the original image remains
  embedded in the drawing and clipboard copies. Raster tracing, external image
  links, and raster DXF/PDF interchange are outside the qualified workflow.
- Geometry Nodes remains **Experimental**. Source elements need a shared parent
  when attaching a modifier; direct Blender/Bonsai connectivity is not shipped.
- Browser clipboard permissions, persistent handles, and external-renderer
  equivalence require the candidate checks recorded below. System-only fonts
  are not portable; Fira Code Italic may appear synthetic in the browser and
  upright in PDF. Prefer qualified bundled font variants for consistent output.

The [capability ledger](https://github.com/elschilling/nanquim/blob/master/docs/capabilities.md)
and [interoperability guide](https://github.com/elschilling/nanquim/blob/master/docs/file-interoperability.md)
describe the supported boundaries. This release does not promote Partial or
Experimental areas to Stable.
